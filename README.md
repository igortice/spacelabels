# SpaceLabels

Repositório público de distribuição do SpaceLabels para macOS.

Este repositório publica somente conteúdo destinado ao público:

- site do GitHub Pages;
- Releases públicas, quando a automação de distribuição estiver pronta;
- downloads e checksums públicos;
- informações de instalação, privacidade e suporte;
- futuro `appcast.xml` usado pelas atualizações do aplicativo.

O código-fonte Swift, os testes e a documentação interna permanecem em um
repositório privado e não são publicados aqui.

## Estado atual

Esta é a fundação pública do projeto. O site inicial confirma o endereço
público e reserva destinos para:

- `/releases` no GitHub;
- download e instalação;
- privacidade;
- suporte;
- futuras atualizações.

Enquanto a publicação automatizada não estiver concluída, o site não anuncia
um download como disponível.

## Site

O conteúdo estático do GitHub Pages vive na raiz da branch `main`:

- `index.html`
- `assets/styles.css`

O site não utiliza JavaScript, analytics, cookies ou recursos remotos.
